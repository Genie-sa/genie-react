Genie lets your coding agent see inside a running React or React Native app and prove that a
change worked.

## How it works

Your agent drives the app with [agent-browser](https://github.com/vercel-labs/agent-browser) or
[agent-device](https://github.com/callstack/agent-device). It clicks, types and reads the screen.
Genie runs inside the app in development and records what happened underneath: which components
rendered and why, which effects ran, and what TanStack Query, TanStack Router and Redux did. The
agent asks Genie through the `genie-react` CLI and gets evidence back, or a pass or fail verdict.

The examples below are real runs against
[`apps/vite-demo`](https://github.com/Genie-sa/genie-react/tree/main/apps/vite-demo). Its
`MemoChild` is wrapped in `memo`, but `App` passes it a new `badge` object on every render.

## Verify a fix

Declare what must stay true, do the interaction, and let Genie decide. `begin` prints the `<id>`:

```bash
npx @genie-react/cli verify begin --session my-agent --name "click the counter" \
  --claim 'render MemoChild max 0' --claim 'render App min 1'
agent-browser --session my-agent click button.counter
npx @genie-react/cli verify end <id> --session my-agent
```

```text
fail vfy_… "click the counter"  1 commit, quiet after 618 ms (react, query)
  1 fail render MemoChild max 0  {renders:1,mounts:0,updates:1,remounts:0,semantics:exact,…}
  2 pass render App min 1  {renders:1,mounts:0,updates:1,remounts:0,semantics:exact,…}
```

After the fix, the same three commands print `pass` and exit 0. A failed claim exits 1.

## Optimize

Measure, change the code, and measure again. Thirty clicks on the counter:

```bash
npx @genie-react/cli call react_clear_renders --session my-agent '{}'
for i in $(seq 30); do agent-browser --session my-agent click button.counter; done
npx @genie-react/cli call react_get_renders --session my-agent '{"component":"MemoChild"}' \
  --fields name,renders,necessity,necessityReason
```

```text
[1]:
  - {name:MemoChild,renders:30,necessity:unnecessary,necessityReason:inputs-unchanged}
```

The full result names the cause: `← props exact badge {referenceOnly:true}`, a new object with the
same contents. Moving `{ text: 'lab' }` out of `App` and repeating the run gives 0 renders.

## Validate every UI state

Put a screen into its loading, empty or error state without clicking through the app:

```bash
npx @genie-react/cli call query_simulate_state --session my-agent \
  '{"queryKey":["greeting"],"state":"error"}'
agent-browser --session my-agent get text '#lab'
npx @genie-react/cli call query_restore_state --session my-agent '{"queryKey":["greeting"]}'
```

The page shows `query: error` until the restore puts the real data back.

## Install

From your app folder:

```bash
pnpm add -D genie-react @genie-react/cli
npx @genie-react/cli init
```

Then [connect your app](/docs/getting-started/install) and [give your agent a task](/docs/getting-started/agent).
