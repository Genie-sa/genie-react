Genie grades each piece of evidence and reports what it could not see.

## Grades

| Value | Meaning | What to do |
| --- | --- | --- |
| `exact` | Genie observed the link directly. | Act on it. |
| `inferred` | The link is likely but not proven. | Confirm it with another check. |
| `unknown` | Genie could not tell. | Do not guess from it. |
| `not-proven-safe` | A render may still affect behavior. | Check the DOM, focus, URL and requests. |

## Coverage

Render and effect reads carry a `coverage` object:

| Field | Meaning |
| --- | --- |
| `complete` | No known gap in what Genie measured. |
| `inputAttributionComplete` | Every captured render has complete input evidence. Only then can you rule out a cause. |
| `semantics` | `exact` counts, or `lower-bound` when some work went unseen. |
| `unobservedCommits` | Commits with no window open. They come with `commits-not-observed`. |
| `refreshCommitsExcluded` | Commits from a Fast Refresh edit, or less than a second after one with no input in between, which Genie does not analyse. They come with `commits-during-fast-refresh`. |
| `pausedCommits` | Commits after `react_profile_stop`. |
| `incompleteBecause` | One entry per gap, with a `next` step. |

An empty list with incomplete coverage does not mean nothing happened. `attribution.status: stale`
means React committed during the read; read again after the app settles. `propsNotEnumerated` means
the props were a `Proxy` or other non-plain object, which Genie does not read.

## Ownership

Each component is `app`, `library` or `unknown`, judged by its own code. The default `appOnly: true`
hides only known library code. `unknown` results stay, and `filteredNote` counts both.

## Effects

A scheduled effect did not necessarily run; `execution.status` says whether its body ran.
`strict-mode-replay` is StrictMode's development re-run. An effect is `hot` after three or more
re-runs in which no dependency changed value. Fewer samples, or dependencies Genie cannot compare,
give `insufficient-data`.

## Source locations

`source.role` says what a location points at: `component-body`, `element-callsite` (the JSX that
rendered it) or `hook-callsite`, the most precise place to edit.

## Refusals

`verify` refuses instead of passing on evidence that cannot prove a claim.

| Reason | Cause |
| --- | --- |
| `no_activity` | No React commit in the window, from any component. A commit from the app's own timer prevents it, so add a `min 1` claim to catch an action that missed the app. |
| `not_quiescent` | Work was still arriving after the app settled, a request the interaction started was still in flight when the settle timeout ran out, or Genie could not observe a settle domain, such as a request watch that stopped. |
| `coverage_incomplete`, `budget_exhausted` | The analysis skipped part of the target. Rerun with the budget it prints. A claim a lower-bound count still decides prints the same budget as `budgetAdvice`. When the interaction itself unmounts more components than Genie keeps (`droppedUnmountFibers`), a rerun loses them again: start from a page that mounts fewer components, or claim a lower bound. |
| `evidence_truncated`, `evidence_unavailable` | Events were evicted or a read failed. `evidence_truncated` also covers a component with more than 2,000 mounted instances, more than `verify` lists, so it cannot check the rest. Start from a page that mounts fewer of them. |
| `evidence_inferred` | The deciding cause is only `inferred`. A `parent` cause is settled when the parent is the component's own wrapper, such as `Connect(Name)`, and the wrapper rendered only for exact causes the claim allows. |
| `target_not_found`, `target_ambiguous`, `target_inactive` | The component name matched nothing, several things, or a hidden or frozen instance. |
| `session_changed`, `window_interrupted`, `window_lost` | The tab reloaded or the window was reset. |
| `code_changed` | Fast Refresh ran during the window. |
| `document_hidden` | The tab was hidden. |
| `override_active` | A Genie override was active. Reset it first. |
| `unsupported_environment`, `capability_unavailable` | A production React build, or a missing collector. `--domains` naming a domain the app does not report refuses at `begin` and names the collector to add, such as `requestWatchCollector()` for `network`. |
| `too_few_samples`, `not_comparable` | Comparison claims without enough comparable runs. |

`inconclusive` is complete evidence that does not decide, such as `strict_mode_replay`.
