The built-in collectors expose 91 tools. Your app may expose fewer, and can add its own under the
`app` group. Every call has the same shape:

```bash
npx @genie-react/cli call <tool> '<JSON input>' --session my-agent
```

Each entry lists the input, an example call, selected output fields, and what the output lets an
agent decide. IDs, counts and times in the examples change with the app. The live contract is the
source of truth for your installed version:

```bash
npx @genie-react/cli tools react_render_causes
```

## Rules for safe use

- Pass `--session` on every call, and open a window before the action you measure.
- Prove a fix with [`verify`](/docs/guides/verify-a-fix), not by reading counts by hand.
- Read coverage, omissions, truncation and evictions before you rely on a result.
- Treat `inferred` and `unknown` as leads, not proof. See [read evidence](/docs/reference/evidence).
- A wait can return `ok: false`, and `devtools_capture_compare` can return `overall: "fail"`, with
  exit 0. Use `--fail-on-result-error` in scripts.
- Restore Query simulations and React overrides when you finish.
